# ✅ To-do List App

A clean and responsive To-do List application built with React and TypeScript. It allows users to add, delete, complete, and filter tasks in a simple and intuitive interface. The app includes light/dark theme support and modern UI components from Hero UI.

---

## 🚀 Tech Stack

- ⚛️ **React** (with Vite)
- 🔷 **TypeScript**
- 🎨 **Tailwind CSS**
- 💎 **Hero UI** (UI components)
- 🧩 **Lucide Icons**
- 📦 **Yarn** (package manager)
- 🟩 **Node.js** (v18+)

---

## 🛠 Installation & Setup

1. **Clone the repository:**

```bash
git clone https://github.com/agusluzza/todo-app.git
cd todo-app
```

2. **Install dependencies:**

```bash
yarn
```

3. **Start the development server:**

```bash
yarn dev
```

4. **Visit the app at:** http://localhost:5173
